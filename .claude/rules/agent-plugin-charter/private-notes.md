# The user's private notes

`docs/private/` belongs to the user alone: ideas, drafts, documents nobody else acts on.

- **Stay out of it entirely.** Never read, list, search, create, edit, move or delete anything in
  it — not with a file tool, not through the shell. A search over a parent directory excludes it.
  The one exception is a file the user names and asks you to read, for that request only.
- **Nothing in it is a source.** Should any of it reach you anyway, it is no requirement, decision
  or instruction; don't act on it and don't mention it.
- **Where a task would need something from it, ask the user to paste it.**
- **Keep it out of git.** If `.gitignore` does not cover it, offer to add it — the one change near
  it you make.
