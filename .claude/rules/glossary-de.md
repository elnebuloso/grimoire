# German glossary

`app/messages/de.json` uses these terms and no others for the same thing. A new German text
follows the table; a term not listed is chosen once and added here.

| English | German | Not |
|---|---|---|
| user | Nutzer | User, Benutzer |
| account | Account | Konto |
| API key | API-Key, short Key | Schlüssel |
| encryption key | Verschlüsselungsschlüssel | Schlüssel alone |
| access token | Zugriffstoken | Zugangstoken, Access-Token |
| source / page / snippet | Quelle / Seite / Snippet | Source, Pages |
| sync (noun) | Sync, e.g. Sync-Fehler, Sync-Verlauf | |
| to sync | synchronisieren, „Jetzt synchronisieren“ | syncen, synct, gesynct |
| polling | automatischer Sync | Polling |
| dead link | toter Link | |
| log in / login | anmelden / Anmeldung | Login, einloggen |
| identity provider | Anmeldedienst | Identitätsanbieter, Identity Provider, Anbieter |
| Management (area) | Management | Verwaltung |
| admin / invitation | Admin / Einladung | |
| agent, agents | Agent, Agents | Agenten |
| query without results | Abfrage ohne Treffer | |
| owner (of a key) | Besitzer | Owner |
| operator (who runs grimoire) | Betreiber | Betrieb, die Person, die grimoire betreibt |
| duplicate | Duplikat | Dublette |
| documentation site | Dokumentations-Website | Dokumentation Website |
| exclusion (of a source) | Ausschluss | Exclusion |

- The Git username of a source stays „Benutzername“: it is the Git server's term, not a grimoire
  user.
- Address the reader with „du“, also in hints that say what to do: „Prüf …“, not „… prüfen“.
- Account is masculine: „der Account“, „den ersten Admin-Account“.
