# SvelteKit

## Project setup
- New SvelteKit projects are created exclusively with the official Svelte CLI `sv` (https://svelte.dev/docs/cli/overview).
- Default command: `npx sv create [path]` (or `pnpm dlx sv create`, `bunx sv create`, depending on the project's package manager).
- Add-ons (e.g. Tailwind, Drizzle, ESLint, Prettier, Vitest, Playwright, mdsvex, …) are also set up only via the CLI: `npx sv add <add-on>`, or directly during creation with `npx sv create --add <add-on> [path]`.

## What you do NOT do
- You never install Svelte, SvelteKit, or add-ons yourself (no `npm install`, no manually creating `svelte.config.js`, `vite.config.ts`, Tailwind configs, etc.).
- You do not run `sv create` or `sv add` yourself.
- You do not write boilerplate files that the CLI would generate anyway.

## What you do instead
- You give the user a short, copy-pasteable step-by-step guide with the exact CLI commands and the options to pick in the interactive prompt (template, TypeScript, add-ons).
- You wait for the user to confirm the installation is done before continuing to work on the code.
- For post-install configuration, you work with the files generated by the CLI rather than rewriting them.
